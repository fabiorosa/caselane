# Portfolio release roadmap

The roadmap is organized by complete reviewer journeys. Technical foundations
support each vertical but do not count as a visible product release by themselves.

## Delivered foundation

- [x] Independent repository, product contract, architecture, schema, migration,
  CI, environment, and responsive visual system.
- [x] Registration, sessions, organizations, invitations, roles, team management,
  server authorization, and tenant isolation.
- [x] Client/contact domain foundation, cursor pagination, primary-contact
  transactions, and the initial client directory.

## Vertical 1: Internal request operation

- [x] Deterministic demo workspace, coherent application shell, and real overview.
- [x] Complete client journey: directory, forms, detail, contacts, and archive.
- [x] Case intake and real operational queue.
- [x] Case workroom, communication, status lifecycle, and trustworthy activity.

Review outcome: a reviewer understands CaseLane and completes the internal
client-request lifecycle without assistance or unfinished routes.

## Vertical 2: Client participation

- [x] Separate portal authorization and client request submission.
- [x] Shared client-visible conversation and status follow-up.
- [x] Adversarial proof that internal notes never reach the portal.

Review outcome: internal team and client participate in the same request while
tenant and visibility boundaries remain enforceable.

## Vertical 3: Public portfolio release

- [x] Settings, security, observability, responsive, and accessibility hardening.
- [x] Fresh-database integration and end-to-end walkthrough suite.
- [ ] English documentation, screenshots, deployment, video, tagged release,
  and portfolio links.

Release outcome: the public product can be discovered, understood, tested, and
evaluated without Fabio or an agent explaining what is unfinished.

## After release

- [ ] Webhook intake and idempotent processing.
- [ ] Rule-based routing with execution history.
- [ ] Human-approved AI suggestions with evaluation evidence.
